# Galaxus Deals

Site statique généré quotidiennement par le projet privé `Ouchix/Galaxus`.

Ce dépôt public contient uniquement les résultats publiables :

- `index.html` : carrousel des articles détectés ;
- `latest.json` : rapport complet exploitable automatiquement ;
- `summary.md` : résumé lisible ;
- `profiles/` : résultats par catégorie.

Les données reposent sur un échantillonnage des historiques de prix visibles sur Galaxus. Elles ne garantissent pas l’analyse exhaustive du catalogue. Le prix et la disponibilité doivent toujours être confirmés sur la fiche Galaxus avant achat.
